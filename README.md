# Warrior Knowledge Quiz CLI Program
A CLI program for testing your FA26 Warrior knowledge

To use:
1) Install python on your computer
2) Open your terminal
3) Navigate to wherever you downloaded this python code (both your questions file and python code should be in the same folder; you can navigate in a terminal by typing "cd" and the name of the folder. Ex: C:\Users\sophia> cd Documents)
4) Type: python warriorKnowledgeTest.py
5) Press enter and follow prompts to begin testing your knowledge. If this fails, alternatively try: python3 warriorKnowledgeTest.py

 Let me know if you need help with any of these steps. I am happy to help! :D
